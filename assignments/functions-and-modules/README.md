# 📘 Assignment: Functions and Modules

## 🎯 Objective

Learn how to organize Python code into reusable functions and import modules to solve a small programming problem efficiently.

## 📝 Tasks

### 🛠️ Create Reusable Functions

#### Description
Write a set of functions that perform common tasks such as calculating area, converting units, or checking a condition.

#### Requirements
Completed program should:

- Define at least two clear functions with meaningful names
- Use parameters and return values to make the functions reusable
- Demonstrate each function with sample inputs in a script or function calls

### 🛠️ Organize Code with Modules

#### Description
Split your logic across multiple Python files or import a built-in module to support your solution.

#### Requirements
Completed program should:

- Use at least one import statement for a module or custom file
- Keep the main program readable and focused on calling functions
- Explain or show how the code is organized into separate responsibilities
