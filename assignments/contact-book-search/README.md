# 📘 Assignment: Contact Book Search

## 🎯 Objective

Learn how to organize information using lists and dictionaries, then search and filter that data to build a simple contact book application.

## 📝 Tasks

### 🛠️ Store Contacts in a Data Structure

#### Description
Create a program that stores contact information such as names, phone numbers, and email addresses in a structured format.

#### Requirements
Completed program should:

- Store contacts using a dictionary or list of dictionaries
- Include at least 3 sample contacts with name and contact details
- Display all contacts in a readable format
- Allow the user to view the full list of entries

### 🛠️ Search and Filter Contacts

#### Description
Add a simple search system so the user can find a contact by name or other details.

#### Requirements
Completed program should:

- Accept a search term from the user
- Search through the contact list for matching names or values
- Display all matching contacts
- Show a friendly message when no contact matches the search

### 🛠️ Add Sorting and Organization

#### Description
Improve the contact book by organizing entries in a clear, user-friendly way.

#### Requirements
Completed program should:

- Sort contacts alphabetically by name
- Give the user the option to add a new contact
- Support removing or updating a contact entry
- Keep the code modular by using helper functions for searching, sorting, and displaying data
