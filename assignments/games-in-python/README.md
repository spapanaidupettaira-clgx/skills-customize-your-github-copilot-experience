
# 📘 Assignment: Games in Python

## 🎯 Objective

Practice core Python skills by creating an interactive game that uses user input, loops, conditionals, and basic string manipulation.

## 📝 Tasks

### 🛠️ Build the Game Logic

#### Description
Create a simple text-based game in Python where the player guesses letters or words within a limited number of attempts.

#### Requirements
Completed program should:

- Choose a word from a predefined list of options
- Display the hidden word as blanks or placeholders for each letter
- Prompt the player to enter a letter guess
- Reveal correctly guessed letters in the word
- Track how many attempts the player has left

### 🛠️ Add Game Flow and Feedback

#### Description
Finish the game so it clearly shows the player's progress and ends with a win or loss message when appropriate.

#### Requirements
Completed program should:

- Prevent repeated guesses from counting as extra attempts
- Show the current guessed letters and remaining attempts
- Display a win message when the word is fully guessed
- Display a lose message when the player runs out of attempts
- Allow the player to play again after each round
